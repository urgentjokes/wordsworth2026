# WordsWorth-J: A Japanese version of WordsWorth.

## Introduction

This is mostly the same as the English version, but it has a few important differences.

## Letters

Instead of the Latin alphabet, it uses the hiragana syllabary. The point assignments are as follows:

Points	Kana Characters
0 Pts	ゃ, ゅ, ょ, っ (Structural Bridge Tiles)
1 Pt	の, い, た, に, て, と, し, は, な, を, か
2 Pts	ら, れ, ま, そ, り, こ, ん, あ
3 Pts	す, お, き, け, つ, ち
4 Pts	ほ, わ, よ, め, み, う
5 Pts	や, さ, ひ, せ, る, く
6 Pts	ゆ, も
7 Pts	ね, む
8 Pts	ろ, ふ
9 Pts	へ
10 Pts	ぬ

### Caboose Rule

The "Caboose Rule" is a twist versus the English version, and solves a key problem inherent in Japanese.

Several kana that are rarely used (and therefore have high point values) are **very commonly used** as verb endings. For example, we often see ぬ as a terminal negation (e.g., せぬ), but it's much less common used elsewhere in a word. The kana for which this problem exists are:

* The entire -うの列 (う、く、す, etc.)
* て

For this reason, when one of these kana appears at the *end* of a word, it is only scored as 1 point. If it's anywhere else in the word, it receives its normal score. Thus, for example:

ぬき: 13 points (10 + 3)
せぬ: 6 points (5 + 1)

In this pair of examples, the ぬ is scored as 10 for the first word, but only 1 for the second.

### Sokuon

The small letters--ゃ、ゅ、ょ、っ--receive zero points, but they take up a whole square. For example:

はっけん takes up four squares, and is worth 6 points (respectively, 1 + 0 + 3 + 2).

### Keyboard

Use a regular QWERTY-style keyboard, but with the following modifications:

Add a 小 key for sokuon. And add a ゛・゜key for dakuten. Also allow the user to simply type, for example, "kyaku", instead of having to type "き ゃ く", one by one. In other words, allow the user not to have to use the 小 or ゛key.
